# ROS 控制与部署

本目录是 `rl_control` ROS 2 控制包，包含状态机、控制接口和策略配置。整套环境、构建及仿真入口见[项目 README](../README.md#-ros2--mujoco-闭环)；ROS 闭环的范围与记录见[闭环说明](../docs/ROS_CLOSED_LOOP_GAP.md)。

## 使用范围

当前步行策略使用 `policy/walk_amp/model/policy.onnx` 和 `policy/walk_amp/config/walk_amp.yaml`。ROS 部署模型有 29 路执行器，步行策略控制其中 23 个关节。`dex_run` 的 ROS 闭环尚需单独适配；包含其他状态或模型不代表其运动已经验收。MIMIC 自由运动未通过此前验证。

包内步行模型及 YAML 增益对应 3300 步行训练记录。切换模型时，须按对应训练快照核对各关节 KP/KD；更换模型不会自动更换增益。脚踝使用串联关节空间增益，真机转换依赖 `sptlib_python`。此前已完成真机地面行走测试；后续新增的末端关节保持逻辑尚未真机复验。测试包与当前包内模型和增益文件一致，实机运行时加载文件的校验值未记录。详情见[步行模型部署说明](../README.md#步行模型部署时的-kpkd-和脚踝转换)和[真机部署记录](../docs/REAL_ROBOT_DEPLOY.md)。

WALKAMP 进入时锁存左右 `elbow_yaw`、`wrist_pitch`、`wrist_roll` 共 6 个关节的实测位置，按 STOP 配置对应的增益保持；当前增益为 KP 80 / KD 5。这些关节不由 23 维行走策略控制。该逻辑已通过仿真验证，真机使用前需核对电机映射和保持命令并进行复验。

## 仿真入口

在项目根目录完成构建并加载 ROS 环境后，使用 `ros2 launch rl_control sim.launch.py`，或通过根目录的 `./run_sim.sh` 启动。请勿同时重复启动整栈和其中的单独节点。本次真机联调采用分步启动脚本，环境、控制权切换和注意事项见[真机部署记录](../docs/REAL_ROBOT_DEPLOY.md)。

## 手柄操作

### 云卓手柄键位映射

xMIGCS支持标准云卓手柄控制，开始使用前先确保所有键都回中，以下是详细键位映射关系：

#### 状态映射关系

##### 单按钮状态切换

| 按钮 | 对应状态 | 功能说明 |
|------|----------|----------|
| C | gotoSTOP | 停止状态 |

##### 组合按钮状态切换

| 切入策略按钮组合| 策略内使用按键 | 对应状态 | 功能说明 |
|------------|----------------|--------------|-------------|
|   所有键(拨中)   |         D      | gotoZERO     | 回到零位状态  |
|   所有拨杆回中   |         先 D，再按 A      | gotoWALKAMP      | WALKAMP 策略状态；A 需在 `gotoZERO` 命令之后按下 |
|   E=1（仿真手柄映射为下拨）   |         A      | gotoBEYONDMIMIC   | BEYONDMIMIC 策略状态   |
|   E=1（仿真手柄映射为下拨）   |         D      | gotoBEYONDZERO   | BEYONDMIMIC 准备状态   |
|   F=1（仿真手柄映射为下拨）   |         长按 A      | gotoMIMIC   | MIMIC 策略状态 |
|   F=1（仿真手柄映射为下拨）   |         D      | gotoMIMICDEFAULT   | MIMIC 默认姿态 |
|   F(上拨)   |         无      | 手柄控制失能，只有停止键可用      | |

拨杆上下方向应结合现场手柄的实际轴值核对；上表中的 E/F 数值条件以控制代码为准。其他策略状态的映射存在不代表其真机运动已经验收。

##### 基础运动控制

| 控制方式 | 功能 |
|----------|------|
| 左摇杆Y1轴 | 前后移动控制（正向为前进） |
| 左摇杆X1轴 | 左右移动控制 |
| 右摇杆X2轴 | 机身旋转控制 |

## 主要目录

- `FSM/`：状态机与状态定义。
- `policy/`：各状态策略、模型和配置。
- `common/`：机器人接口、数据与手柄输入。
- `config/`：仿真和真机配置。
- `launch/`：仿真及真机 ROS 启动文件。
